# Arte-Sano

Arte-Sano es el menú digital de un bodegón. Desde el menú público se pueden buscar platos por nombre, categoría y precio. Las personas registradas pueden iniciar sesión y consultar su perfil. El panel de administración permite crear, editar y borrar platos y categorías.

## Cómo ejecutarlo

Necesitás Node.js y MongoDB.

1. En la carpeta api, copiá .env.example como .env y completá la conexión a MongoDB y la clave JWT.
2. Abrí una terminal en api y ejecutá:

```bash
npm install
npm run dev
```

3. En frontend, copiá .env.example como .env. La URL de la API es http://localhost:3001.
4. Abrí otra terminal en frontend y ejecutá los mismos comandos.
5. Entrá a http://localhost:5173. La documentación de la API está en http://localhost:3001.
